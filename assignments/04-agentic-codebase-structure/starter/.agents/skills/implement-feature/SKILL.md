# Implement a feature

1. Read the selected task, `AGENTS.md`, and any scoped guidance for affected files.
2. Inspect the related route, data model, and existing tests.
3. State the expected behavior, edge cases, and affected files before editing.
4. Add a failing behavioral test for the requested success path and a failure or edge case.
5. Implement the smallest change that satisfies the task and preserves existing behavior.
6. Run `pytest` from this directory.
7. Summarize the change, test result, and any remaining risks.
